# PostgreSQL DBA

Laboratorio de administración PostgreSQL sobre Rocky Linux 9.

Incluye SQL, roles, backups y restauración, PITR, rendimiento,
monitorización, replicación y automatización con Ansible.

Cada apartado documenta su objetivo, entorno, comandos, validación,
resultado y limitaciones. No representa una instalación de producción.

No se publican secretos, claves privadas, backups con datos reales ni
información identificable.
